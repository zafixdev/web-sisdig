Minggu 1: Pendahuluan Sistem Digital & Konversi Bilangan

Definisi, karakteristik, Analog vs Digital, aplikasi sehari-hari, dan dasar sistem bilangan (Biner, Oktal, Heksadesimal, Desimal). Konverter di bawah memakai metode Biner sebagai basis utama.

📖 Definisi

Sistem digital bekerja dengan data berbasis angka biner (0 dan 1) untuk pengolahan informasi dengan akurasi tinggi. Data bersifat diskrit (terputus), bukan kontinu — sehingga mudah diproses, disimpan, dan ditransmisikan komputer.

🛡️ Karakteristik

  • Andal: tahan noise / gangguan eksternal dibanding analog.
  • Diskrit: 0/1 = off/on sirkuit elektronik.
  • Efisien: semua data (teks, gambar, suara) direpresentasikan biner.

🏠 Aplikasi Sehari-hari

  • Otomasi rumah: lampu pintar, termostat, kunci digital.
  • Komunikasi: ponsel, WiFi, Bluetooth, konferensi video.
  • Konsumen & IoT: smart TV, konsol game, kulkas pintar.
  • Komputasi & AI: hitung cepat, big data, algoritma learning.

🔢 Dasar Bilangan (MSB/LSB)

Basis 2 (0,1). Setiap digit = bit. MSB = Most Significant Bit, LSB = Least Significant Bit.

Kelompok bit: 4-bit = Nibble, 8-bit = Byte, 16-bit = Word.

Biner→Desimal: jumlahkan bobot 2n. Desimal→Biner: bagi berulang dengan 2. Oktal (basis 8) & Heksa (basis 16, 0-9 A-F) memadatkan biner.

🔢 Desimal → Biner: bagi berulang dengan 2

Bagi bilangan dengan 2 berulang kali, catat sisa dari bawah ke atas (LSB → MSB).

🔠 Biner → Heksadesimal: kelompok 4-bit

Kelompokkan per 4 bit dari kanan (LSB), tiap kelompok = 1 digit heksa (0–9, A–F).

🎱 Biner → Oktal: kelompok 3-bit

Kelompokkan per 3 bit dari kanan (LSB), tiap kelompok = 1 digit oktal (0–7).

➕ Biner → Desimal: jumlahkan bobot 2n

Bit 1 dikali bobot posisinya (2n dari kanan, mulai 20=1), lalu dijumlahkan.

Minggu 2: Bilangan Negatif & Operasi Biner

Sign-Magnitude, 1's Complement, 2's Complement (standar CPU), negatif di Hex/Octal, pengurangan via penjumlahan, overflow, sign extension, end-around carry.

SM

MSB = tanda (0=+, 1=−), sisa bit = magnitudo. 8-bit: −127..+127. Ada +0 (00000000) dan −0 (10000000). Contoh +13=00001101, −13=10001101.

C1

Negatif = NOT semua bit. 8-bit: −127..+127, masih ada ±0. Contoh −13 = 11110010. Butuh end-around carry.

C2 ⭐

Negatif = NOT + 1. 8-bit: −128..+127, satu nol. Aritmetika paling sederhana. Contoh −13 = 11110011, −37 = 11011011, −1 (16-bit) = FFFF.

➕ Sign-Magnitude (SM)

MSB = bit tanda (0 = +, 1 = −), sisa bit = magnitudo (nilai mutlak).

Struktur 8-bit: 1 bit tanda + 7 bit magnitudo. Rentang −127..+127.
+13:

0000 1101

MSB=0 (+), magnitudo 13
−13:

1000 1101

MSB=1 (−), magnitudo 13
Double zero: +0 = 00000000, −0 = 10000000 — memperumit logika perbandingan hardware.

Coba sendiri di tab Perbandingan: masukkan −25 → SM = 10011001.

🔄 1's Complement (C1)

Negatif = inversi (NOT) semua bit dari representasi positif. Rentang 8-bit −127..+127, masih ada ±0.

Contoh −13: +13 = 00001101 → NOT → 11110010. Cek di tab Perbandingan!
End-around carry: jika penjumlahan C1 menghasilkan carry keluar MSB, carry itu ditambahkan kembali ke LSB. Contoh 5 + (−5) → −0 pada C1.

⭐ 2's Complement (C2) — standar CPU/MCU

Rumus: C2 = NOT(semua bit) + 1. Rentang 8-bit −128..+127, hanya satu nol.

11011010 + 1 = 11011011₂ = 0xDB → inilah −37!

Unggul karena: satu nol + pengurangan cukup pakai adder (tanpa subtractor). C2→Desimal: jika MSB=1, nilai = −(2ⁿ − U). Contoh 11100110₂: U=230, 256−230=26 → −26.

➕ Operasi C2: A − B = A + (C2 dari B)

Adder only
-
Aturan overflow: positif + positif = negatif → OVERFLOW; negatif + negatif = positif → OVERFLOW; beda tanda tak pernah overflow. Formula hardware: carry-in(MSB) XOR carry-out(MSB). Coba 100 + 60 (seharusnya +160 > +127).

↔️ Sign Extension & C1 Carry

Perlebar 8→16 bit: salin MSB. Contoh −37: 11011011 → 11111111 11011011. C1: jika ada carry keluar, tambahkan ke LSB (end-around carry). C2 menghindari ±0 → lebih praktis.

Minggu 3: Aljabar Boolean & Gerbang Logika

Variabel & operator AND/OR/NOT, prioritas NOT→AND→OR, hukum Boolean, tabel kebenaran ↔ ekspresi, bentuk standar SOP (Σm) / POS (ΠM).

🔌 Operator Dasar

AND (·), OR (+), NOT (garis atas / '). Prioritas: kurung dulu, lalu NOT, AND, OR. Contoh: A + B·C' = A + (B·C').

📜 Hukum Penting

  • Identitas: A+0=A, A·1=A
  • Komplemen: A+A'=1, A·A'=0
  • Idempoten, Involusi (A'')=A
  • De Morgan: (A·B)'=A'+B', (A+B)'=A'·B'
  • Absorpsi: A+A·B=A; Konsensus, Distributif

📐 SOP vs POS

SOP / Minterm: jumlah dari kali — tiap suku memuat semua variabel. Contoh G = xy + x'y. Tanpa komplemen dibaca 1.
POS / Maxterm: kali dari jumlah — contoh (x'+y)(x+y'). Tanpa komplemen dibaca 0.

⚙️ Prioritas operasi (tanpa kurung): NOT → AND → OR

Kurung selalu dikerjakan dulu. Contoh: A + B·C' = A + (B·C') — NOT C dulu, AND dengan B, terakhir OR dengan A.

➕ SOP / Minterm (Σm)

Tiap suku = AND semua variabel (tanpa ' dibaca 1, dengan ' dibaca 0), suku-suku di-OR. Contoh: G = x'y'z + xyz + x'y'z' → mintermnya m1 + m7 + m0. Dibangun dari baris output = 1.

✖️ POS / Maxterm (ΠM)

Tiap suku = OR semua variabel (tanpa ' dibaca 0, dengan ' dibaca 1), suku-suku di-AND. Contoh: f(x,y) = (x' + y)(x + y'). Dibangun dari baris output = 0.

Praktik: buka tab SOP, atur tabel F, lalu baca hasil POS (ΠM) — maxterm = komplemen indeks minterm. Contoh f = Σm(0,2,4) → POS = ΠM(1,3,5,6,7).

Konversi POS↔SOP: kembangkan sukunya (distributif) lalu sederhanakan dengan hukum Boolean / K-Map (Minggu 4).

Minggu 4: Penyederhanaan Karnaugh Map (K-Map)

Lebih intuitif dari aljabar manual. Aturan: kelompokkan 1-2-4-8 sel bertetangga (wrap-around boleh), tiap sel beda 1 variabel (Gray code), sebesar & sesedikit mungkin, X (don't care) boleh ikut.

🗺️ Mengapa K-Map?

Tabel kebenaran disusun 2D dengan Kode Gray (00 → 01 → 11 → 10) — hanya 1 bit berubah antar kotak bersebelahan, sehingga variabel redundan terlihat langsung dan bisa dieliminasi.

⚡ Aljabar manual

Butuh kejelian hukum, rentan keliru, sulit pastikan minimal.

⭐ K-Map

Grafis & intuitif, grup 1-2-4-8-16, hasil minimal SOP/POS.

📏 5 Aturan Emas Pengelompokan

1
Ukuran = 2n

Hanya 1, 2, 4, 8, 16. Dilarang 3, 5, 6!

2
Persegi / persegi panjang

Tidak boleh diagonal atau bentuk L.

3
Sebesar mungkin

Makin besar grup → makin banyak variabel tereliminasi.

4
Tepi menyambung (wrap-around)

Kiri-kanan & atas-bawah tersambung; 4 sudut = 1 grup!

5
Boleh overlap

Satu angka 1 boleh masuk beberapa grup.

2️⃣ K-Map 2 Variabel (A, B) — baris A, kolom B

Contoh: Q = AB + A'B + AB' (m1, m2, m3) → grup m1+m3 mengeliminasi A (sisa B), grup m2+m3 mengeliminasi B (sisa A) → Q = A + B.

3️⃣ K-Map 3 Variabel — baris A, kolom BC (Gray)

Contoh: Q = ABC' + AB'C' + AB'C + ABC (m4–m7, seluruh baris A=1) → satu grup 4 → B dan C tereliminasi → Q = A.

4️⃣ K-Map 4 Variabel — baris AB, kolom CD (Gray)

Contoh: Q = A'BC'D + ABC'D + A'BCD + ABCD (m5, m13, m7, m15 — kolom CD=01 & 11 pada baris B=1) → grup 4 mengeliminasi A dan C → Q = BD.

👻 Don't Care (X)

Kondisi yang tak terjadi / tak peduli hasilnya. Di Lab, klik sel 2× untuk menjadikannya X.

Aturan: X boleh dianggap 1 untuk memperbesar grup, atau 0 (diabaikan) jika tak membantu. Jangan paksa X masuk grup kecil.

🚨 Studi Kasus: Alarm Gedung (4 sensor)

A=pintu, B=jendela, C=gerak, D=asap. Alarm = A·C + B·C + D → minterm 1,3,5,6,7,9,10,11,13,14,15.

🅿️ Latihan: Gerbang Parkir

A=kartu valid, B=kendaraan ada, C=penuh, D=darurat. Buka jika A·B·C' + D → minterm 1,3,5,7,9,11,12,13,15.

📋 Cheatsheet Minggu 4 — K-Map

Aturan kilat

Grup = 2ⁿ (1,2,4,8,16) • persegi • sebesar mungkin • wrap-around • boleh overlap • Gray 00-01-11-10.

Eliminasi
