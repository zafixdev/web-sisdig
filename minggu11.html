Minggu 11: Memori — Hierarki, RAM & ROM

Hierarki memori, organisasi address×data, operasi baca/tulis RAM, jenis ROM, dan menghitung kapasitas.

🏛️ Hierarki

Register → Cache (SRAM) → RAM (DRAM) → Flash/SSD → HDD. Makin ke bawah: makin besar, murah, lambat. Cache menjembatani cepat-lambat.

🧮 Organisasi

Memori 2n×m: n address line, m bit data. Kapasitas bit = 2n×m. Contoh 1K×8 = 1024×8 = 8 Kbit = 1 KB.

🏨 Analogi: hotel + meja kerja

Address = nomor kamar hotel: memberi nomor 5 → resepsionis (decoder!) mengantarmu ke tepat 1 kamar dari 16 kamar — persis cara address decoder memilih 1 sel memori. Data = isi koper di kamar itu.

Hierarki = meja kerja vs gudang: barang di meja (register/cache) diambil sedetik tapi muat sedikit; barang di gudang (HDD) muat banyak tapi butuh jalan jauh. Komputer menaruh "barang yang sedang dikerjakan" di meja dan sisanya di gudang — itulah prinsip lokalitas yang membuat cache efektif.

🧮 Membaca tulisan 1K×8

"1K×8" dibaca: 1024 lokasi (K = 1024, bukan 1000!), tiap lokasi 8 bit (1 byte). Total = 8192 bit = 1024 byte = 1 KB. Rumus umumnya: n address line → 2n lokasi.

Contoh ujian: chip 11 address line, data 8 bit → 211×8 = 2048×8 bit = 2048 byte = 2 KB. RAM vs ROM: RAM seperti papan tulis (ditulisi ulang, terhapus saat listrik mati), ROM seperti buku cetak (awet, tapi mengubahnya butuh "cetak ulang" = programmer/sinar UV/sinyal elektrik).

📀 ROM — memori baca saja

Diisi sekali (pabrik/programmer): PROM (sekali tulis), EPROM (hapus UV), EEPROM/Flash (hapus elektrik). Isi tetap walau listrik mati → cocok untuk bootloader & tabel konversi (mis. BCD→7seg di Minggu 7 bisa diimplementasikan sebagai ROM 16×7).

Decoder = ROM sederhana: address decoder memilih 1 baris, tiap baris menyimpan pola output tetap.

📋 Cheatsheet Minggu 11 — Memori

Hierarki: register > cache > RAM > flash > HDD. Kapasitas = 2ⁿ × m bit (n=address, m=data). RAM baca-tulis volatil; ROM non-volatil (PROM/EPROM/EEPROM).
